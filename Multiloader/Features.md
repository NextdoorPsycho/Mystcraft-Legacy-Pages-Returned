# Features

## Core Systems
- Age creation: Descriptive books (Agebooks) create new Mystcraft dimensions the first time they are linked through a link panel.
- Linking system: Linkbooks store a destination and teleport entities when activated or used through portals.
- Link properties: Link panels and modifier pages apply flags like intra-linking, relative links, disarm, platform generation, momentum preservation, and following behavior.
- Instability system: Each Age has an instability score derived from its pages and symbols that drives risk and behavior.
- Instability effects: High instability can trigger environmental hazards such as decay, meteors, colored lightning, potion effects, erosion, and extra ticks.
- Decay corruption: Unstable Ages can spread a destructive decay block that replaces and destroys terrain.
- Portal system: Book receptacles mounted on crystals create link portals that transport entities to a book’s destination.
- Star Fissure exits: Ages can generate a Star Fissure gateway that returns entities to the overworld spawn or their respawn point.
- Personal pocket dimensions: Personal link books create and link to a player-specific pocket dimension with a return link.
- Datapack symbol + grammar system: Symbols, grammar rules, and overrides are loaded from datapacks to define how Ages are built.
- Age worldgen customization: Symbols can modify terrain types, biome controllers, weather, colors, structures, and populators during Age generation.
- In-game book GUI: Linkbooks and Agebooks open a custom interface for viewing pages and activating links.
- Archivist villager profession: A custom villager profession trades Mystcraft items and symbol pages and spawns in a dedicated village house.
- Mystcraft commands: Server commands manage Ages, symbols, instability, weather/time, chunk regen, and debug utilities.

## Items and Blocks
- Pages: A single item type that can be blank, a link panel, or a symbol page used in Age creation.
- Agebook: The descriptive book that stores a full Age description and links to the Age it creates.
- Linkbook: A reusable book that links to a specific location and can drop as an entity when used.
- Unlinked Linkbook: A blank linkbook that binds to the current position when right-clicked.
- Personal Link Book: A special linkbook that always targets the player’s personal pocket dimension.
- Book Binder: A workstation that binds pages and leather into Agebooks or Linkbooks.
- Writing Desk: A multiblock workstation used to write symbols onto pages using ink.
- Ink Mixer: A workstation that mixes inks and dyes to create link panels with properties.
- Ink Vial: A container item that stores a quantity of colored ink for writing.
- Ink Fluid/Bucket: A placeable fluid form of ink used for crafting and filling vials.
- Booster Pack: A consumable item that opens into a small set of random pages.
- Folder: An ordered, writable, 16-page workspace container for organizing pages.
- Portfolio: An unordered, sorted, 64-page archive for long-term page storage.
- Guidebook: An in-game manual that explains Mystcraft systems and gameplay.
- Glasses: Wearable optics that reveal hidden symbol data and instability overlays.
- Book Receptacle: A block that holds a book and, when attached to a crystal, powers a portal.
- Crystal: A block that powers book receptacles and forms part of the portal structure.
- Link Portal: The active portal block created by a powered receptacle that teleports entities.
- Link Modifier: A workstation that applies modifier pages to existing linkbooks.
- Bookstand: A display block that holds a book and lets players link from it.
- Lectern: A taller book display block that functions similarly to the bookstand.
- Star Fissure: A block that serves as an exit gateway from an Age to the overworld.
- Decay Block: A corruption block that spreads through unstable Ages with different behaviors by type.
- Linkbook Entity: The in-world entity used to represent dropped linkbooks and agebooks.
- Meteor Entity: A falling projectile spawned by instability or commands.
- Colored Lightning Entity: A custom lightning effect used by instability and special features.
- Mystcraft Falling Block Entity: A custom falling block used by instability effects.
