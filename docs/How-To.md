# How To Use Mystcraft (Player Flow)

## Getting Started

1) Obtain a Guidebook (if enabled by config, you get one on first spawn).
2) Craft or find a Writing Desk, Book Binder, and Ink Mixer.
3) Create Ink Vials or Ink Buckets.
4) Write symbols onto blank pages using the Writing Desk.
5) Bind pages into a Descriptive Book with the Book Binder.
6) Use the Descriptive Book to create an Age.

## Creating an Age (Descriptive Book)

1) Gather pages:
    - Terrain, Biomes, Weather, Lighting, Features, Structures, Colors.
2) Write them into a book in your desired order.
3) Open the Descriptive Book to link to the new Age.

Tip: Missing or conflicting symbols add instability. Use more specific symbols
for more stable Ages.

## Linkbooks

1) Craft an Unlinked Linkbook.
2) Use it at a location to bind a destination.
3) Use the Linkbook to travel to that destination.

Link flags can be applied with inks or modifiers (if enabled).

## Managing Instability

- Stable Ages: Use complete symbol sets, avoid conflicting symbols.
- Unstable Ages: Expect environmental effects, decay, and hazards.
- Config can limit or scale instability.

## Using Datapacks for Symbols

1) Create a datapack under:
   `saves/<world>/datapacks/`
2) Add symbol JSONs under:
   `data/<namespace>/mystcraft/symbols/`
3) Reload with `/reload`.
